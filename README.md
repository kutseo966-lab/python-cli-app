# 🚀 Python CLI App

Простое Python CLI приложение с автоматической сборкой через GitHub Actions.

## 📦 Возможности

- ✅ Информация о системе
- ✅ Кроссплатформенность
- ✅ Автоматическая сборка
- ✅ Создание артефактов

## 🚀 Использование

```bash
python app.py
```

## 🏗️ Сборка

Сборка происходит автоматически при пуше в `main` ветку через GitHub Actions.

## 📋 Workflow

- Тестирование на Python 3.9, 3.10, 3.11, 3.12
- Сборка артефактов
- Автоматический релиз
